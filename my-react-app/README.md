# ფოტოს ანალიზი

React + Vite + Tailwind CSS-ზე აწყობილი მარტივი ფოტოს ანალიზის ინტერფეისი.

## გაშვება VS Code-ში

გაუშვი frontend და backend ორ ცალკე VS Code ტერმინალში.

ტერმინალი 1 — frontend:

```sh
cd my-react-app
npm install
npm run dev
```

ტერმინალი 2 — backend:

```sh
cd server
npm install
npm run dev
```

პირველ გაშვებამდე, პროექტის მთავარ საქაღალდეში, შექმენი `server/.env` ნიმუშის ასლით:

```powershell
Copy-Item server/.env.example server/.env
```

გახსენი `server/.env`, ჩაანაცვლე `GEMINI_API_KEY`-ის placeholder შენი მოქმედი Gemini API გასაღებით და შეინახე. გასაღები ჩაწერე მხოლოდ `server/.env`-ში — არ გააზიარო ჩატში და frontend-ის კოდში არ ჩასვა. შემდეგ გააჩერე და თავიდან გაუშვი backend ტერმინალში (`Ctrl+C`, შემდეგ `npm run dev`), რადგან `.env`-ის ცვლილება ავტომატურად არ გადაიტვირთება. ტერმინალში გამოჩნდება გაფრთხილება, თუ გასაღები ვერ მოიძებნა. Vite `http://localhost:5173`-ზე მუშაობს, `/api` მოთხოვნები კი `http://localhost:3001`-ზე გადამისამართდება.

## ფოტოს ხელით შემოწმება

გახსენი Vite-ის მიერ ნაჩვენები მისამართი (ჩვეულებრივ `http://localhost:5173`), აირჩიე JPEG, PNG ან WebP სურათი 5 მბ-მდე, სურვილისამებრ ჩაწერე კითხვა და დააჭირე „გაანალიზე“. პასუხი გამოჩნდება შედეგის ველში. შეცდომის შემთხვევაში, გადაამოწმე ორივე ტერმინალში სერვერების მდგომარეობა და backend-ის კონსოლის შეტყობინებები.
